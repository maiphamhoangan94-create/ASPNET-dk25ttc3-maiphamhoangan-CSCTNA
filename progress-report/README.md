Mỗi tuần tiếp theo, thêm một file `YYYY-MM-DD.md` theo ngày kết thúc tuần, ghi công việc thực tế, mã commit minh chứng và việc dự kiến tiếp theo. Phải commit và đẩy cả thay đổi dự án lẫn báo cáo lên repository; chỉ có file báo cáo không đủ đáp ứng yêu cầu. Các báo cáo này mô tả thay đổi trong Git, chưa khẳng định chức năng đã được kiểm thử thành công.
