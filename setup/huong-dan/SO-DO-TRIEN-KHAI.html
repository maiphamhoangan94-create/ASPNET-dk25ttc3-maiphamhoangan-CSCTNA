Thứ tự triển khai: cài SQL Server → khôi phục .bak → cấu hình kết nối → chạy profile http trong Visual Studio → mở trình duyệt. Visual Studio và SDK chỉ cần khi biên dịch/chỉnh sửa mã nguồn.

Nếu tách máy web và máy SQL: đổi Server trong chuỗi kết nối, cấu hình TCP/IP, tường lửa và quyền tài khoản SQL tương ứng. Gói hiện tại cấu hình cho trình diễn cục bộ.
