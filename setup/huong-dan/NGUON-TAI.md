# Nguồn tải phần mềm

Các đường dẫn được ghi nhận ngày 25/10/2026.

1. SQL Server Express – liên kết người dùng cung cấp:
   https://go.microsoft.com/fwlink/p/?linkid=2216019&clcid=0x409&culture=en-us&country=us
   Khi tải gói này, liên kết chuyển đến SQL2025-SSEI-Expr.exe.
2. Visual Studio Community – trang người dùng cung cấp:
   https://visualstudio.microsoft.com/thank-you-downloading-visual-studio/?sku=Community&channel=Stable&version=VS18&source=VSLandingPage&cid=2500&passive=false
   Tải bootstrapper tương ứng từ https://c2rsetup.officeapps.live.com/c2r/downloadVS.aspx?sku=community&channel=stable&version=VS18&source=VSLandingPage&cid=2500 .
3. .NET 10 SDK (chỉ cần để build mã nguồn): https://dotnet.microsoft.com/en-us/download/dotnet/10.0
4. SSMS (nếu cần giao diện restore): https://learn.microsoft.com/en-us/ssms/install/install

Các bộ cài khởi động SQL Server và Visual Studio cần Internet để tải thành phần. Tải phần mềm riêng theo các liên kết trên. Để cài offline, tải đầy đủ media SQL Server bằng chức năng Download Media của bộ cài; với Visual Studio, tạo layout theo tài liệu https://learn.microsoft.com/en-us/visualstudio/install/create-an-offline-installation-of-visual-studio .
